# Mohammad Zbeeb

Personal website, publications, and research notes. Built with static HTML, CSS, and JavaScript and hosted on GitHub Pages.

The homepage lives at `/blog/`, the notes archive at `/blog.html`, and articles at `/blog/posts/`. The root and the legacy `/about/` route redirect to the homepage.

Run a local preview from the repository root:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173/`. No build step or dependencies are required.
